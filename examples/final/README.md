# Final example

Full evaluation of the included HAPPO, fixed MAPPO and heuristic: 3 scenarios, 20 paths per scenario and 366 periods per path. See `run.json` for model hashes and settings, `summary.csv` for means, and `episodes.csv` for individual paths.

Open `report.html` locally for the self-contained report. The PNG figures are also available separately. To regenerate the report and full period records, run `python demo.py --output outputs/demo` from the repository root. The bulky `steps.csv` is generated at runtime rather than included here.
